設定

設定はサーバーと同期されますか？

一部の設定は同期されます。投稿の初期公開範囲、ミュート・ブロック、サーバーのフィルターは、同じアカウントで使うほかのアプリとも共有されます。文字サイズやテーマ、メディアの表示、端末内ワードミュートなどは、この端末のアプリだけの設定です。

サーバーの設定は起動時や閲覧アカウントの切り替え時に読み込まれ、ミュート・ブロック・フィルターは各管理画面でも更新できます。投稿の初期設定を変更しても、編集中の投稿や保存した下書きは書き換えず、変更した設定を次に新しく書き始める投稿から使います。

通知と通信

アプリを閉じている間も通知を受け取るには？

設定 → 通知で、受け取りたいアカウントの「バックグラウンドの通知（Push）」をオンにしてください。通知の許可や再認証を求められた場合は案内に従い、状態が「有効」になるまで確認してください。Android側でもアプリの通知を許可する必要があります。

ストリーミングは何をする機能ですか？

閲覧中のアカウントの新着投稿や通知を、接続中に受け取る機能です。初期設定ではアプリを表示していない間は停止します。設定 → タイムラインと通信で、オン・Wi-Fiのみ・オフを選べます。

Push通知と定期確認は両方オンにしていいですか？

はい。Push通知を使っていても、定期確認は補助として動きます。定期確認は約15分ごとに通知を確認しますが、端末の状態によって間隔や到着時刻は変わります。

アプリを使っている間のバナーだけ止められますか？

設定 → 通知の「アプリ表示中のAndroid通知」をオフにしてください。アプリを表示している間のAndroid通知が出なくなりますが、アプリ内の通知一覧や通知の受信は止まりません。

通知が届かないときは何を確認すればいいですか？

Android側の通知許可と、設定 → 通知にある対象アカウントのPushの状態を確認してください。アプリを使っている間だけ出ない場合は「アプリ表示中のAndroid通知」も確認してください。通信状態や端末の省電力設定などで遅れたり届かなかったりする場合があり、通知の到着時刻や、すべての通知が届くことは保証できません。

Pushをオフにしたのに「解除待ち」と出ます。

通信などの問題で、通知の登録解除を完了できていない状態です。アプリを起動するか再び表示すると登録解除を再試行し、画面の再試行ボタンからもやり直せます。解除が終わるまでは解除に必要な情報を端末に保持します。

投稿と画像

画像は自動で小さくなりますか？

アプリでは画像を自動で縮小・再圧縮しません。容量を減らしたい場合は、添付する前に画像を編集してください。投稿先のサーバーで加工される場合はあります。

投稿する前に画像が送信されますか？

はい。添付を選ぶと、本文を書いている間にサーバーへアップロードします。この時点で投稿が公開されるわけではありません。投稿をやめた場合の添付ファイルの保存・削除は、サーバーの仕様に従います。

画像と動画を同時に添付できないのはなぜですか？

アプリでは動画・音声を1件のみ添付でき、画像などのほかのメディアと一緒には添付できません。画像と動画を両方投稿したい場合は、投稿を分けてください。

添付の送信に失敗したときはどうすればいいですか？

添付欄で詳細を確認し、再試行してください。サーバーでの処理が終わったか確認できない場合は、「再確認」で状態を確認できます。

フィルター

サーバーのフィルターと端末内ワードミュートは何が違いますか？

サーバーのフィルターの設定は同じアカウントで使うほかのアプリと共有されます。端末内ワードミュートはこの端末のアプリだけで本文や内容警告（CW）に含まれる言葉を判定します。両方を併用できます。

フィルターV1のサーバーでも使えますか？

アプリではサーバーのフィルターV2に対応しており、旧方式のV1には対応していません。V2を使えないサーバーでは、設定 → ミュート・ブロックの管理にある「端末内のワードミュート」を使えます。V1への切り替えやワードの自動移行は行いません。

フィルターはすべての画面や通知に効きますか？

いいえ。サーバーのフィルターは検索・探索・タグ・お気に入り・ブックマークには適用しません。端末内ワードミュートはこれらの画面でも使えますが、Androidの通知欄やバナーには、どちらのフィルターもアプリ側での判定を適用しません。

データの削除

アカウントをアプリから削除すると何が消えますか？

設定 → アカウント管理で登録を削除すると、そのアカウントの下書き・編集中の入力・アプリに取り込んだ添付ファイルのコピー・設定・履歴・閲覧キャッシュ・通知などを削除します。再ログインしても以前の下書きや履歴は戻りません。サーバー上のアカウントや投稿、元の写真、ほかのアカウントのデータ、アプリ共通設定は残ります。

「ストレージ」で削除すると下書きも消えますか？

アプリの設定 → ストレージで削除するのは、表示に使った画像のキャッシュです。アカウント・設定・下書き・編集中の添付は残ります。画像を再び表示すると、必要なキャッシュが作り直されます。

Androidの「ストレージを消去」も同じですか？

いいえ。Android側のストレージ消去は、アプリのアカウント登録や下書きなども対象になります。必要な内容を別の場所に控え、Pushをオフにして解除が終わったことを確認してから、ストレージを消去してください。端末のデータを消すだけでは、通知の登録が解除されない場合があります。

データの保存や削除の方針、お問い合わせ先は、ポリシー・お問い合わせをご覧ください。

# Nagisaの紹介・使い方・ポリシー

GitHub Pagesで公開する、ビルド不要の静的HTMLサイトです。共通の見た目は `styles.css`、トップページ専用の見た目は `home.css` で管理します。外部フォント・アクセス解析・UIライブラリは使用しません。

## ページ構成

- `index.html`：ストア紹介文を元にしたアプリ紹介、使い方・ポリシーへの案内、Google Playと連絡先
- `guide/index.html`：1ページの使い方Q&A。設定・通知と通信・投稿と画像・フィルター・データ削除の5分類
- `policy/index.html`：プライバシーポリシー・利用規約・安全基準・削除案内・問い合わせ

使い方は `guide/index.html` の1ファイルで管理します。項目別ページと試作ページは置かず、目次から同じページ内の各項目へ移動します。旧項目別URLからの転送ページはありません。

使い方は、利用者が疑問に思う点を質問にし、結論と必要な操作・注意を数文で答えます。技術的な内部処理の説明は省き、削除対象・サーバーごとの違い・通知の制約など、利用判断に必要な情報を残します。サーバー対応に関する共通の注意はトップページにまとめます。

## 編集と確認

各フォルダーの `index.html` を直接編集します。説明を変更した際は、アプリの実装と配布版での動作に照らして内容を確認してください。

ローカルでは、このフォルダーをルートとする静的HTTPサーバーで確認できます。Pythonがある場合の例：

```powershell
python -m http.server 8765 --bind 127.0.0.1
```

PC幅とスマートフォン幅、ページ間リンク・目次・ポリシーの各項目を確認します。トップページはライト表示に固定し、使い方とポリシーはライト・ダーク表示の両方を確認します。リンクは `/nagisa-policy/` のようなプロジェクト配下でも動く相対パスです。JavaScriptは旧トップページのポリシー項目へのリンク互換だけに使用し、本文はJavaScriptなしで読めます。

## 公開前の確認

- GitHub Pagesは既存の公開設定に従い、このリポジトリのルートを公開します。ローカル編集だけでは公開されません。
- アプリやPlayなどのプライバシーポリシーURLは、`https://ponpokoo.github.io/nagisa-policy/policy/#privacy` へ更新してください。旧ルートURLはアプリ紹介になるため、従来のリンク元を確認します。
- 旧URLの `#privacy`、`#terms`、`#child-safety`、`#deletion`、`#contact`、`#publication` は、新しいポリシーページの同じ項目へ移動します。JavaScriptを使えない場合も、旧項目の位置に本文へのリンクがあります。
- ポリシーの2026年10月24日の改訂は、現在のRelay保存方式とアカウント登録削除の動作を反映しています。利用規約・安全基準の内容は元の文書を維持しています。
- 配布先・配布版で利用可能な機能を確認してください。アプリの初回案内・ガイドへのリンクは別途実装する計画で、このサイトの作成によって追加されるものではありません。
